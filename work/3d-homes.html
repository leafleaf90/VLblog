How it works

  1. Write and say what you need: new build, renovation, which floor, which rooms.
  2. If it is a fit, you email the 2D floor plan. Dimensions help. A known room size is enough if the drawing has no scale.
  3. I build the 3D house in RoomSketcher.
  4. You walk through it. We change walls, openings, or furniture if something is off.
  5. You get the model, the stills, and any AI renditions we agreed on.

What I need from you

  • The 2D floor plan
  • Ceiling height if it is not standard
  • Which rooms to spend time on
  • Finish notes only if they change the look: wood versus tile, a dark kitchen, a white box. The exact grout color can wait.

Price

This starts at €500 for a straightforward floor: the RoomSketcher model and stills. A whole house, or extra AI renders, is more. Write and I will quote it.
