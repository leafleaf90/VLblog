I build custom apps in Nuxt and Tailwind, then I set up the parts that make them run: hosting, a database that fits the use case, and a deploy pipeline.

After launch I can keep it running. Updates, broken builds, small features, the work that starts when people besides you log in.

What this can include

  • A Nuxt app, styled with Tailwind
  • Hosting chosen for the project
  • Database and file storage based on what you are actually storing, how often it changes, and who needs to see it
  • CI/CD for preview and production deploys
  • Ongoing maintenance after it is live

How it works

  1. You describe the product, the users, and what already exists. A messy note is fine. A 40-page spec is usually not a gift.
  2. I propose a stack and a first slice: what ships, where it is hosted, what we store, and what we skip.
  3. I build, you review on a preview URL, we adjust.
  4. It goes live with deploys you can trust. Maintenance is optional and scoped separately if you want it that way.

If you mainly need a domain, email, and a small site, that is tech setup, not this. If you need a Shopify storefront, that is theme work.
